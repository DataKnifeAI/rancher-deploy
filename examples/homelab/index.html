Example Homelab Topology

Reference layout: Ubiquiti / UniFi fabric → two-node Proxmox VE (Dell PowerEdge) → storage (MD1420 SAS → TrueNAS, Ceph NVMe, local ZFS) → Rancher-managed RKE2 guests. Framed as an example — adapt gear labels, IPs, and VLANs to your site.

Cluster: Ash Nodes: pve1 · pve2 Net: UniFi (example gear) DAS: MD1420 → SAS → TrueNAS Guest VLAN: 14

01 Stack overview

Top-down: UniFi gateway and aggregation switch carry LACP into Proxmox bonds; MD1420 is a direct SAS shelf on the TrueNAS node (not an Ethernet “shared shelf”); guests land on VLAN 14. This repo’s Terraform creates the guest layer only — UniFi, host bonds/bridges, and Ceph/ZFS live outside Terraform.

03 · Storage

MD1420 → SAS → TrueNAS is a direct-attached shelf (HBA / dual SAS links). Cluster pods reach that pool over the storage network via NFS/iSCSI CSI — not via SAS to Proxmox.

Dell MD1420

DAS shelf · example

JBOD / expander chassis with SAS disks for the TrueNAS pool.

  • Attach dual SAS to TrueNAS HBA
  • Not Ethernet-shared to pve1/pve2
  • Not Proxmox guest disks
SAS direct-connect · HBA / multipath

TrueNAS

storage net · 192.168.9.10

Owns the MD1420 via SAS; exports pool over Ethernet to the cluster.

  • NIC on UniFi storage VLAN / bond peers
  • Pool SAS
  • Export NFS / iSCSI → CSI
  • Class truenas-csi-nfs

Per-node local

zfspool not shared

local-vm-zfs — primary datastore for Rancher/RKE2 VM disks (clusters.*.storage). Local SSDs per host. Also rpool / local-zfs, local, images-import.

Cluster shared (Ceph)

rbd shared

Pool data (~8 OSDs on host NVMe across pve1/pve2). Ceph mons on 192.168.9.x. Optional inactive pool pathfinder. Terraform example prefers local ZFS for OS disks.

Backup & PV path

PBS NFS / CSI MD1420 SAS

PBS for VM backups. TrueNAS at 192.168.9.10 serves pool SAS (disk behind SAS) as Kubernetes PVs.

Terraform → cloud-init VMs on local-vm-zfs · CSI PVs via NFS

02 How layers connect

Ethernet paths stay on UniFi; the MD1420 path is SAS-only into TrueNAS, then NFS/CSI rides the storage VLAN back to guests.

03 Address & VLAN cheat sheet

Segment Bridge / bond · UniFi Example addresses Used for
Management vmbr0 ← bond0 ← UniFi LACP 192.168.8.5–6, GW .1 Proxmox UI/API, Corosync, host default route

04 Storage roles (example)

Datastore Type Shared? Role in this stack
local-vm-zfs ZFS pool No Default VM disk target for Terraform clusters
data Ceph RBD Yes Shared images; NVMe OSDs on both hosts
PBS Proxmox Backup Server Yes VM backup target
images-import / local Directory No Cloud image import, ISOs, templates
TrueNAS SAS NFS via CSI (disks via SAS) Yes (to pods) MD1420 direct-SAS to TrueNAS; PVCs over 192.168.9.10

Disk roles on the example hosts: boot SSDs → rpool; Intel SATA SSDs → local-vm-zfs; host NVMe → Ceph OSDs. The MD1420 is labeled as example DAS media attached by SAS to TrueNAS — not as invented serial-numbered devices and not as a Proxmox-attached shelf.
